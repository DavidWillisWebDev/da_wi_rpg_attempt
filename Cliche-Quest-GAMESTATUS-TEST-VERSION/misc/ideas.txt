Idea #1: class system
  Concept:
    A class system, similar to games like Fire Emblem or Final Fantasy.
    Different classes have different effects on the gameplay. (mages have higher magic power, but less physical power, brawlers have higher physical power, but less magic power, etc.)
    Classes also have unique abilities exclusive to said class.

  Notes:
    Will need a new attribute in the character constructor, called "class."
    character.class will be a string property. It will initially start as none ("").


Idea #2: save system
  Concept:
    A save system, similar to most RPG games.
    The game's progress would be saved after a prompt asking the player if they want to save.
    This would help reduce frustration whenever a player exits.

  Notes:
    Will need several new functions.
    This would have to be implemented very late into the game's development.

Idea #5: Spell Range
  Concept:
    Spell range, depending on spell.
    Some spells target more than one.

  Notes:
    New functions.
    New property in Spell object, being "range."
      spell.range's default value is a string variable, being "1."
      If spell targets multiple targets, then the spell.range's value increases.
      If the spell targets every targets, then spell.range becomes "all."
