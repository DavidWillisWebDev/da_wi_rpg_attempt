main.py - data and processes for the main game

battle.py - data and processes for any individual battle ... needs to have a connecting eventNode for win and loss cases

choices.py - data and proceses for any individual choices ... choice is usually going to be a question to the user ... every choice is connected to an eventNode

dialogue.py - data and proceses for any individual dialogue

character.py - data about characters

eventNode.py - an event ... could be battle or dialogue ... needs to have a set of choices determining how this would branch off

helper.py - contains helper functions that can be used by all files in the project
